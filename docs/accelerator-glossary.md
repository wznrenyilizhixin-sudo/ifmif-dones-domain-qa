# IFMIF-DONES 加速器设施术语表（中英对照）

用途：给 DONES 域检索、query expansion、人工阅卷和答案校验提供最低限度的术语骨架。表中的“为什么会被出题”不是官方押题，而是根据公开设施结构、sample 题型分布和数值/因果问法做的可解释推断。

> 使用边界：缩写存在跨文献歧义时，必须以检索到的原文定义为准。表中标为“需回原文确认”的缩写，不要直接写进最终答案。

| # | English | 中文 | 为什么会被出题 |
|---:|---|---|---|
| 1 | IFMIF-DONES | 国际聚变材料辐照设施—示范堆导向中子源 | 整个 D 域的核心对象；问建筑、系统、目标或边界条件时必须先确认全称与缩写。 |
| 2 | d-Li neutron source | 氘—锂中子源 | 通过氘束轰击锂靶产生高通量中子，是设施物理链条的起点。 |
| 3 | deuteron / D+ | 氘核 / 氘离子 | 加速器注入粒子和核反应参与者，常与束流能量、流强或靶反应一起考。 |
| 4 | ion source | 离子源 | 产生氘离子束的第一级设备，问“束流从哪来”时的最小答案。 |
| 5 | ECR ion source | 电子回旋共振离子源 | LIPAc 的氘离子源类型；容易考工作机制或与其他源型比较。 |
| 6 | LIPAc | 直线 IFMIF 原型加速器 | 许多加速器参数来自原型验证，题目常把 LIPAc 与 IFMIF-DONES 设计区分开。 |
| 7 | RFQ | 射频四极加速器 | 低能段的聚束与加速结构，常考频率、功率、注入/出口能量。 |
| 8 | MEBT | 中能束流传输线 | 连接 RFQ 与超导直线段，涉及束流匹配、再聚束和传输损失。 |
| 9 | SRF linac | 超导射频直线加速器 | DONES 高能加速段的核心；常与腔型、低温模块、梯度或功率系统联考。 |
| 10 | HWR | 半波长谐振腔 | 超导直线段使用的腔型之一，适合考“为什么选这种腔”。 |
| 11 | cryomodule | 低温恒温器 / 低温模块 | 把超导腔、磁体、真空和低温管路集成在一起，问集成或维护时会出现。 |
| 12 | accelerating cavity | 加速腔 | 通过射频场给束流能量，题目常要求区分腔型、频率、梯度和功率。 |
| 13 | RF power system | 射频功率系统 | 给 RFQ、再聚束腔和 HWR 供功率，数字与设备数量容易被出成事实题。 |
| 14 | beam transport line | 束流传输线 | 把束流从一段设备送到下一段；问损失、匹配或诊断位置时的容器概念。 |
| 15 | beam dump | 束流收集器 / 束流垃圾桶 | 吸收未进入靶或调试束流的高功率束，涉及热负荷、辐射和安全联锁。 |
| 16 | beam current | 束流电流 / 束流强度 | 高功率设施的第一类硬数字，通常和单位、连续/脉冲模式一起考。 |
| 17 | beam energy | 束流能量 | 影响核反应产额、穿透深度和辐射场，常以 MeV 或 GeV 形式出现。 |
| 18 | duty cycle | 占空比 | 决定平均功率、热负荷和活化水平；predictive 题常要求由它推算运行量。 |
| 19 | emittance | 发射度 | 描述束流相空间面积；影响能否通过 RFQ/传输线或达到靶上束斑要求。 |
| 20 | beam envelope | 束流包络 | 束流横向尺寸沿传输线的变化，常出现在束流动力学或匹配问题。 |
| 21 | beam optics | 束流光学 | 用磁元件控制束流轨迹和尺寸；适合比较不同光学方案或解释损失。 |
| 22 | quadrupole magnet | 四极磁铁 | 横向聚焦的基本元件，问聚焦/散焦或束流匹配时的关键件。 |
| 23 | beam diagnostics | 束流诊断 | 测量束流位置、尺寸、流强或损失；题目常比较“破坏性 vs 非破坏性”。 |
| 24 | destructive beam diagnostic | 破坏性束流诊断 | 测完会拦截或改变束流；最容易考它对束流造成什么后果。 |
| 25 | OTR | 光学渡越辐射 | 带电粒子穿过不同介质界面时产生的辐射，适合与闪烁机制比较。 |
| 26 | scintillation | 闪烁（发光） | 材料沉积能量后发光；与 OTR 的关键差别是是否依赖能量沉积。 |
| 27 | beam profile | 束流剖面 / 束斑分布 | 描述束流横截面，常由 OTR、闪烁屏或丝扫描得到。 |
| 28 | BPM | 束流位置监测器 | 实时测量束流中心位置，常与反馈、轨道校正和安全联锁连接。 |
| 29 | wire scanner | 丝扫描仪 | 以细丝扫过束流获取剖面，通常涉及热负荷和破坏性程度。 |
| 30 | Faraday cup | 法拉第筒 | 直接收集电荷测流强，简单但会阻挡束流。 |
| 31 | beam loss monitor | 束损监测器 | 监测局部束流损失和辐射，常用于机器保护与调试。 |
| 32 | machine protection system | 机器保护系统 | 把设备状态与联锁逻辑连起来，问异常时“先做什么”会出现。 |
| 33 | safety interlock | 安全联锁 | 条件不满足时禁止或切断运行；高频出现在安全、维护和故障题。 |
| 34 | target assembly | 靶组件 | 液锂靶、背板、喷嘴等部件的总称，问更换、维护或热工设计时出现。 |
| 35 | liquid lithium target | 液态锂靶 | 氘束与锂发生反应并带走热量的界面，是 D 域最核心的工程对象之一。 |
| 36 | beam footprint | 束斑 / 束流落点 | 靶上受照区域的形状和面积，直接影响局部热流与中子产额。 |
| 37 | beam rastering | 束流扫描 / 光栅化 | 通过移动束斑降低局部峰值热流，常问为什么要扫。 |
| 38 | lithium loop | 锂回路 | 将液态锂从靶区送至换热和净化系统的循环，是热工、化学和放射性问题的共同背景。 |
| 39 | heat exchanger | 热交换器 | 把锂回路热量传给二回路；sample 中出现过流量与温度类问题。 |
| 40 | ICS branch | ICS 支路 | sample 中出现过 bypass ratio，但缩写含义需回原文确认；先别猜全称。 |
| 41 | bypass ratio | 旁通比 / 旁路比 | 分流比例影响流量、温度与停留时间，适合做计算或参数事实题。 |
| 42 | volumetric flow rate | 体积流量 | 常以 m³/s、L/s 或 m³/h 出现；必须做单位换算和数量级检查。 |
| 43 | cold trap | 冷阱 | 通过降温让杂质析出，问净化、堵塞或维护时出现。 |
| 44 | nitrogen trap | 氮阱 / 氮冷阱 | sample 出现过在线氮阱温度；温度单位和操作状态是关键。 |
| 45 | impurity control | 杂质控制 | 锂中杂质会影响腐蚀、传热和氚行为，常问控制手段及其理由。 |
| 46 | corrosion | 腐蚀 | 液态锂与结构材料长期接触的核心风险，影响材料选择和维护周期。 |
| 47 | tritium | 氚 | 核反应产物和放射性核素，涉及产额、提取、渗透、剂量与安全。 |
| 48 | tritium extraction system | 氚提取系统 | 从锂回路回收氚；常问原理、材料、效率或与安全的关系。 |
| 49 | getter bed | 吸气剂床 | 通过化学吸附/吸收捕获氢同位素，适合问材料与再生逻辑。 |
| 50 | Be-7 / beryllium-7 | 铍-7 | 锂受照后的重要放射性产物，sample 直接问库存和主导活度时间。 |
| 51 | half-life | 半衰期 | 决定核素随时间衰减的快慢；可能导致“取整后算衰变常数”类计算。 |
| 52 | decay constant | 衰变常数 | 与半衰期成反比关系，是 0/1 判分下必须给对数值和单位的典型题。 |
| 53 | activation | 活化 | 材料受中子照射后变成放射性核素；是维护分类和辐射防护的前提。 |
| 54 | decay heat | 衰变热 | 停机后放射性衰变继续放热，影响冷却、维护窗口和安全分析。 |
| 55 | dose rate | 剂量率 | 决定人员能否进入和需要何种屏蔽，常带 Sv/h、mSv/h 单位。 |
| 56 | radiological zoning | 辐射分区 | 按剂量/污染风险划分区域，决定工作许可和个人防护。 |
| 57 | hands-on maintenance | 人工维护 / 直接接触维护 | 与遥操作维护相对；sample 直接问何时允许，必须同时考虑活度和剂量率。 |
| 58 | remote handling | 遥控维护 / 遥操作 | 高辐射区的标准维护方式，涉及机械臂、工具、视野和容错。 |
| 59 | shielding | 屏蔽 | 用材料降低中子/γ 剂量，常问材料选择、厚度或与维护的关系。 |
| 60 | ALARA | 合理可行尽量低 | 辐射防护原则，可作为解释“为什么宁愿遥操作”的规范理由。 |
| 61 | neutron irradiation | 中子辐照 | 设施存在的目的；与温度、剂量、能谱共同决定材料损伤。 |
| 62 | displacement per atom / dpa | 原子离位次数 / 位移损伤剂量 | 聚变材料损伤的常用指标，常要求与中子通量/时间区分。 |
| 63 | neutron spectrum | 中子能谱 | 决定核反应和材料损伤；IFMIF-DONES 强调模拟聚变第一壁谱。 |
| 64 | first wall | 第一壁 | 聚变堆面向等离子体的关键部件，是材料测试需求的主要来源。 |
| 65 | RAFM steel | 低活化铁素体/马氏体钢 | 聚变结构材料候选，适合考低活化、辐照脆化与热稳定性。 |
| 66 | irradiation rig | 辐照装置 / 辐照盒 | 装试样并控制温度的部件，涉及远程维护和高通量测试。 |
| 67 | post-irradiation examination / PIE | 辐照后检验 | 对辐照试样做力学、显微和放射性分析，是材料资格认证的证据链。 |
| 68 | high flux test module / HFTM | 高通量测试模块 | 主要辐照模块之一，sample/官方材料可能用缩写；需区分模块类型。 |
| 69 | DEMO | 示范聚变堆 | IFMIF-DONES 服务的下游目标，解释设施为什么需要聚变谱中子时常用。 |
| 70 | fusion material qualification | 聚变材料资格认证 | 把设施目的、辐照参数、PIE 和数据可信度串起来的顶层概念。 |

## 检索时优先扩展的别名

- `DONES` ↔ `IFMIF-DONES` ↔ `International Fusion Materials Irradiation Facility – Demo Oriented Neutron Source`
- `HX` ↔ `heat exchanger`
- `Li loop` ↔ `lithium loop` ↔ `liquid lithium loop`
- `Be7` ↔ `Be-7` ↔ `beryllium-7`
- `D+` ↔ `deuteron` ↔ `deuterium ion`
- `RH` ↔ `remote handling` ↔ `remote maintenance`
- `dpa` ↔ `displacements per atom`
- `OTR` ↔ `optical transition radiation`
- `BPM` ↔ `beam position monitor`
- `HWR` ↔ `half-wave resonator`
- `MEBT` ↔ `medium energy beam transport`
- `RFQ` ↔ `radio frequency quadrupole`
- `SRF` ↔ `superconducting radio frequency`

## 复核提醒

- `ICS` 的全称和边界在公开材料中可能有歧义，最终答案必须回到竞赛语料原文。
- `Be-7` 的库存、主导活度时间、靶/换热器中的分布是数值和因果双重敏感项，不能只凭常识回答。
- `hands-on maintenance` 不是单一阈值题，通常要同时说明剂量率、活度、区域分类和维护策略。
